# @deepseek-ai/dsh-itranslation

DSH profile bundle for the Itranslation whole-book translation preset.

This package is the `dsh plugin` installable entry point for the project. It
does not contain runtime code by itself: it contributes the host patch that
mounts the Itranslation client UI and depends on the host tools and client
packages that the agent preset needs.

See the repository README for the full install steps.
